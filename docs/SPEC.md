# 仕様とロードマップ

## コンセプト

**プログラムの計算が導く、今日の献立。** 献立はアルゴリズム（数理最適化）が決め、AI はその上でリアクション・解説・相談・モチベーション維持を担当する。

## 方針

- 判断の中心は決定的なプログラム（最適化・栄養計算）。AI は計算結果やアプリの状態を**構造化データ**で受け取り、必要ならプログラムを**ツール**として呼ぶ
- AI がなくても全機能が使える
- 試行錯誤しやすいよう、データ（食材・料理）・計算（planner）・画面（features / pages）を分ける
- 画面が増えたら整理する。スマホの下部ナビは 6 項目まで

## ディレクトリ

| パス                 | 内容                                                        |
| -------------------- | ----------------------------------------------------------- |
| `src/lib/food/`      | 食材・料理・栄養基準・気候のデータと計算（UI に依存しない） |
| `src/lib/planner/`   | 献立の最適化（HiGHS の LP モデル生成・Worker・評価）        |
| `src/lib/db/`        | IndexedDB（献立・買い物・在庫）                             |
| `src/features/`      | 機能ごとの UI 部品とストア                                  |
| `src/pages/`         | ページ（ルート）                                            |
| `src/components/ui/` | 汎用 UI 部品                                                |
